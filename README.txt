MATHS FEYNMAN TECHNIQUES - Android par install karne ke steps
==============================================================

Ye app ek "PWA" hai: Chrome isay asli app ki tarah phone par install karta hai
(home-screen icon, fullscreen, offline). Iske liye sirf ek baar free hosting
chahiye (https link). GitHub Pages sabse aasan hai:

1) github.com par free account banao (phone ke Chrome mein, "Desktop site" on karo).
2) New repository banao, naam: maths-feynman  (Public).
3) "uploading an existing file" par tap karo, aur is zip ke ANDAR ki SAARI files
   (index.html, style.css, script.js, manifest.json, service-worker.js aur 4 icon .png)
   select karke upload karo. Commit changes dabao.
   (Pehle zip ko Files app se Extract kar lo.)
4) Repository > Settings > Pages > Branch: main / (root) > Save.
5) 1-2 minute baad link banega:  https://TUMHARA-USERNAME.github.io/maths-feynman/
6) Us link ko Android Chrome mein kholo. App ke Home screen par "Install app"
   ka button aayega, ya Chrome menu (3 dots) > "Install app" / "Add to Home screen".
7) Install hone ke baad app icon se khulegi - internet ke bina bhi chalti hai.

Note: pehli baar link internet se kholna zaroori hai (app cache hone ke liye).
Progress phone ke andar hi save hota hai.
